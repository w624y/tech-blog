# 如何使用 ui-ux-pro-max

## 简介

ui-ux-pro-max 是一个专业的 UI/UX 设计助手技能，提供可搜索的设计系统数据库，帮助你快速获取现代化的 UI/UX 设计参考和最佳实践。

## 使用方法

### 1. 激活技能

在需要 UI/UX 设计建议时，直接调用 Skill 工具：

```
技能名称: ui-ux-pro-max
```

### 2. 功能特性

- **设计系统参考**：提供多种现代化的 UI 设计模式和组件
- **响应式设计建议**：适配不同屏幕尺寸的最佳实践
- **色彩搭配**：专业的主题色彩方案和渐变效果
- **动效设计**：流畅的过渡动画和交互效果
- **排版建议**：字体选择和排版规则

### 3. 使用场景

- 需要为 React 组件添加样式时
- 不知道如何实现某个视觉效果时
- 需要设计响应式布局时
- 想了解最新的 UI 设计趋势时

### 4. 示例请求

你可以这样提问：

- "帮我设计一个现代的登录页面"
- "首页的分类卡片应该用什么样式？"
- "如何实现平滑的过渡动画？"
- "给一个数据展示表格的设计参考"

### 5. 配合设计稿

结合设计预览文件夹中的 HTML 原型：

```
d:\8_面试\demo\react\react-blob\design-preview\
```

可以先在设计预览中查看效果，再使用 ui-ux-pro-max 获取对应的 React 实现建议。

## 注意事项

- 该技能专注于前端 UI/UX 设计
- 提供的是设计建议和代码参考，具体实现需要根据项目需求调整
- 设计建议基于现代 Web 开发最佳实践
